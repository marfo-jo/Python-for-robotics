# Project rules
- The full spec is in PROMPT.md. The approved plan is in docs/PLAN.md and
  build progress is in docs/PROGRESS.md. Read all three at session start.
- NEVER create, edit, or complete files in my-solutions/. That folder is the
  learner's own work.
- Verify every lesson's examples and hidden tests with local Python (conda
  env "robotics-course") before marking it done.
- Build one module per session. When done, commit with a clear message and
  update docs/PROGRESS.md.
- Ask before installing any new dependency.
- Never commit API keys or config.local.json.
